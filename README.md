# Achievement Engine V1.3

獨立成就引擎的圖片世界 Renderer 示範版。V1.3 沿用 V1.0 的 `core/achievement-engine.js`，沒有修改核心引擎邏輯。

## 使用方式

1. 將 ZIP 解壓縮。
2. 直接打開解壓縮後根目錄的 `index.html`。
3. 點選「完成下一關」測試 45 個里程碑；也可輸入指定關卡。
4. 進度會依 `gameId: maze-world-demo` 保存在瀏覽器，可匯出、匯入或重設。

## 目前圖片階段

- `assets/world/001.jpg`：初始灰階世界。
- `assets/world/002.jpg`：第 44 關天空恢復色彩的參考圖。
- `assets/world/003.jpg`：第 45 關迷宮環境恢復色彩的參考圖。
- `assets/world/004.jpg`：最終完整世界（V1.3 已替換為包含第45步完整數獨解答的新母圖）。

## 重要：物件圖層尚待拆分

第 1～43 關已建立 43 個獨立的物件獎勵 ID 與圖層載入插槽，檔名規則為：

`assets/layers/object-01.png` 至 `assets/layers/object-43.png`

每張圖應為與世界底圖相同尺寸（2048×1153）的透明 PNG，僅保留該關要恢復色彩的物件，其餘像素透明。完成後放入上述位置，Renderer 會依照已解鎖進度自動疊加；未放入的圖層會自動略過，不會影響進度資料。

目前版本不會假裝已完成物件拆圖，也不會用重新生成的圖片取代使用者原圖。四張 JPG 原始素材均完整保留。

## 專案結構

- `core/`：V1.0 核心引擎（原樣沿用）
- `renderer/`：圖片世界呈現與圖層疊加
- `data/`：45 個里程碑示範設定
- `assets/world/`：四張世界階段原圖
- `assets/layers/`：待放入的透明物件圖層
- `adapters/`：預留遊戲事件轉接模組
- `tests/`：核心引擎測試

## 邊界與限制

- 本版為單機展示版，尚未連接數獨或其他遊戲。
- 第 1～43 關的透明物件 PNG 尚未製作；需要依 004.jpg 精準拆分與遮罩處理。
- 第 44、45 關以使用者提供的 002、003、004 圖片作階段呈現。
- 進度儲存仍沿用 V1.0 的 localStorage 機制。


## V1.3 測試介面修正
- 移除「指定關卡」輸入與「完成指定關卡」按鈕。
- 測試介面只保留「完成下一關」，每次依序完成一個里程碑，避免跳關造成進度顯示與解鎖順序混淆。
- V1.0 核心引擎未修改；本次只調整示範介面與 Renderer 的測試流程。
